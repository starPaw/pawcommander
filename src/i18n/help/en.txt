PawCommander

Usage
  pawcommander [FOLDER]
  pawcommander open FOLDER
  pawcommander workspace NAME
  pawcommander search QUERY [FOLDER]
  pawcommander update-macos INSTALLED_APP RELEASE_ZIP TRUSTED_RELEASE_KEY
  pawcommander restore-macos INSTALLED_APP SAVED_BACKUP_APP
  pawcommander --help

With no arguments, restore the saved session.
Open a folder, restore a named workspace, or search for file names and masks.
Search uses the current directory when FOLDER is omitted.
The open, workspace and search commands use separate windows with temporary settings.
Quit the installed app before running an update or restore.
Use -- before operands that start with a dash.

Exit codes
  0  Command completed successfully
  1  Settings or application startup error
  2  Invalid arguments
  3  Target unavailable or update or restore failed
