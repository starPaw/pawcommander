# PawCommander 0.2.0 Preview

This preview targets macOS on Apple Silicon. It improves file-operation safety, clipboard behavior and navigation.

## Changes

- Queue file operations and inspect detailed per-file results, including skipped, failed and incomplete moves.
- Detect interrupted operations and inspect owned temporary copies before deciding how to recover them.
- Retry unfinished transfers and undo supported renames and moves with checks that preserve existing files.
- Optionally verify copies with SHA-256. Moves between volumes or backends verify the copy before removing the source and report any source that remains.
- Improve Finder copy/paste and Move Here behavior, including groups, conflicts and repeat paste after Skip.
- Preserve SFTP sessions when editing equivalent IPv6 addresses; improve Unicode path suggestions and recent/frequent folder navigation.
- Activate a pane by clicking its empty space, margins or status area while keeping its selection.
- Improve cancellation responsiveness for content searches with regular expressions.
- Cancel a file drag with Escape after Finder becomes active. Repeated drops use Finder’s standard replacement dialog.
- Refresh the Rust toolchain and desktop dependencies.

## Installation

Download `PawCommander-0.2.0-macOS-arm64.zip` and `SHA256SUMS.txt`. Quit the previous app, extract the ZIP and replace PawCommander in Applications. Settings from the public 0.1.0 preview use the same identifiers.

See the [macOS installation guide](../MACOS_INSTALL.md) for checksum and first-launch instructions. The archive includes third-party licenses, required corresponding source and a manifest identifying the source commit.

## Preview limits

- The binary targets macOS 11 or later and is tested on macOS 27.0.1. Older macOS versions and Intel Macs are not verified by this release.
- The app is ad-hoc signed, without Developer ID signing or Apple notarization.
- Windows and Linux binaries and native acceptance are outside this release. Their source implementations remain experimental.
- File verification does not provide a filesystem snapshot or a guarantee against power loss. Cross-backend moves can finish with a valid destination copy and a remaining source; inspect the result before retrying manually.
- SFTP symlinks and special objects are not copied. A move within one SFTP connection uses the server’s rename behavior. ACLs and extended metadata are not fully transferred across backends.
- Recovery and Undo apply only to supported, recorded operations; automatic app updates are not included.
