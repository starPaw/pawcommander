# PawCommander 0.3.0 Preview

This preview is for Apple Silicon Macs. It adds more ways to inspect files, compare folders and recover interrupted transfers.

## Changes

- Inspect interrupted local and SFTP copies or moves. Resume from verified data and check the destination before removing the original.
- Compare folders and review a one-way or two-way synchronization plan before applying it.
- Browse and edit ZIP and TAR archives. Inspect archive contents and extract selected entries.
- Preview PDFs, CSV and TSV tables, audio and video on macOS. Use the hex view to inspect and search file bytes.
- Browse WebDAV folders over HTTPS. This preview supports listing, navigation and refresh.
- On macOS 27, PawCommander checks the drag session before allowing Finder to copy the selected files. If macOS reuses a session, keep holding the mouse while PawCommander retries. If it asks you to drag again, repeat the gesture.
- Verify release archives with the project's Ed25519 key. The new command-line updater can install a later signed version and retain a copy of the previous app for rollback.

## Installation

Download the Apple Silicon ZIP, `SHA256SUMS.txt` and `SHA256SUMS.txt.sig` from the release page. Verify the archive, quit PawCommander, then replace the app in Applications. Existing settings and connections from the 0.2.0 preview use the same identifiers. See the [macOS installation guide](../MACOS_INSTALL.md).

The binary targets macOS 11 or later. Native verification used macOS 27.0.1 on Apple Silicon. The app has an ad-hoc code signature. Apple Developer ID signing and notarization are unavailable for this preview. Linux and Windows source builds remain experimental.
