# Security policy

PawCommander is an early-stage desktop file manager. Security fixes target the latest code on the default branch; older releases do not have a separate maintenance commitment.

## Report a vulnerability privately

Use [GitHub's private vulnerability reporting](https://github.com/starPaw/pawcommander/security/advisories/new) for issues involving credential exposure, host verification, unintended access, or destructive file operations.

Include the affected version, OS, reproduction steps using disposable files or a local test server, and the expected impact. Do not include real passwords, private keys, personal files, or access-bearing links. Please avoid public issues with exploit details until the report has been reviewed.

For ordinary bugs without sensitive details, use the issue tracker.
